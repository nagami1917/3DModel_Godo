# 3DModel_Godo

Repository art direction: [`3D_MODEL_PROMPT.md`](3D_MODEL_PROMPT.md).

An isolated Godot 4 procedural character/creature generator foundation is in [`godot_character_generator/`](godot_character_generator/). See its README for current capabilities, limitations, and editor setup. The included static wanderer has been revised toward the hooded, modular ranger look in the user-provided Drive **Reference** folder; its source links, CC0 license note, model bounds, and rebuild steps are in [`character_info.md`](godot_character_generator/assets/characters/medieval_wanderer/character_info.md). The reference model files are not bundled. Existing source assets and pipeline files have not been replaced.
