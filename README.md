# 3DModel_Godo

Repository art direction: [`3D_MODEL_PROMPT.md`](3D_MODEL_PROMPT.md).

An isolated Godot 4 procedural character/creature generator foundation is in [`godot_character_generator/`](godot_character_generator/). See its README for current capabilities, limitations, and editor setup. It includes a static ranger-inspired wanderer and a new static knight asset based on the proportions and low-poly style of the user-provided Drive **Reference** folder. See the [wanderer notes](godot_character_generator/assets/characters/medieval_wanderer/character_info.md) and [knight notes](godot_character_generator/assets/characters/medieval_knight/character_info.md) for source/license links, model details, and rebuild steps. Reference model files are not bundled.
